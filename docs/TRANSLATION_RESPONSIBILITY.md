# 📝 翻譯責任釐清

**簡短回答你的問題**：

## 是否需要先翻譯？

### ✅ **是的，必須先翻譯**

```
你的步驟：
1. 寫好中文問題 + 5-9 個變體
2. 寫好中文答案（摘要 + 詳細）
3. ⭐ 翻譯成英文（所有問題變體 + 答案）
4. ⭐ 翻譯成泰文（所有問題變體 + 答案）
5. 交給我進行品質檢查
6. 我套用優化標準 + 入庫
```

### ❌ **不能做的事**

- ❌ 只提供中文，等我翻譯
- ❌ 用 Google Translate 快速翻譯
- ❌ 翻譯成英文但泰文先欠著
- ❌ 事後再補翻譯

---

## 為什麼？

### 1. **Method B 策略設計**

我們選擇的 Method B 方案是：
- 預先翻譯（一次性）✅
- 前端快取（初始化載入）✅
- 語言切換零延遲（使用快取）✅

**不是**：
- 動態翻譯（每次生成）❌
- 機器翻譯（低準確度）❌
- 事後翻譯（拖累進度）❌

### 2. **SEO 和 AI 引擎需要完整翻譯**

```
Google SEO 爬蟲：
  - 看到的應該是自然的英文頁面
  - 不能是機器翻譯或不完整的翻譯

ChatGPT/Perplexity 等 AI 引擎：
  - 同樣需要高質量的英泰翻譯
  - 才能在回答時引用和推薦
```

### 3. **數量必須完全對應**

```json
你提供的中文：
{
  "utterance_patterns": [
    "應該先訂好機票住宿，還是先預約滑雪教練",
    "先訂教練還是先訂機票",
    "先訂教練還是先訂住宿",
    "要先預約教練嗎",
    "機票住宿要先訂嗎",
    "先訂教練比較保險嗎",
    "要先預約教練",
    "機票住宿要先訂",
    "先訂教練比較保險"
  ]  // 9 個
}

你提供的英文翻譯必須對應：
{
  "utterance_patterns_translations": {
    "en": [
      "Should I book flights and accommodation first, or book a ski instructor first?",
      "Should I book a coach first or flights first?",
      "Should I book a coach first or accommodation first?",
      "Do I need to book a coach in advance?",
      "Should I book flights and accommodation first?",
      "Is it safer to book a coach first?",
      "I need to book a coach in advance.",
      "Flights and accommodation should be booked first.",
      "It's safer to book a coach first."
    ]  // 必須是 9 個，不能少
  }
}

你提供的泰文翻譯同樣需要 9 個！
```

## 翻譯建議

### 如果你有翻譯能力

直接翻譯即可。需要注意：
- ✅ 逐句翻譯，不能漏掉任何變體
- ✅ 語法自然（尤其英文）
- ✅ 專有名詞統一（CSIA、CASI、野澤等）

### 如果你沒有翻譯能力

建議：
1. **英文** - 找英文母語使用者審核
   - 可用 Google Translate 初稿
   - 但英文使用者必須改正

2. **泰文** - 找泰文母語使用者（重要！）
   - 泰文特別容易出現格式錯誤
   - 如果有專業翻譯者更好

3. **預算考量**
   - 1 個 FAQ = 約 300-500 字翻譯量
   - 20-30 個 FAQ = 6000-15000 字
   - 專業翻譯費用: 約 $100-300（英文）+ $100-300（泰文）

## 檢查清單

在提交翻譯前，確保：

- [ ] **中文問題** - 1 個主問題 + 5-9 個變體
- [ ] **中文答案** - 摘要 40-80 字 + 詳細說明
- [ ] **英文翻譯** - 完整翻譯，非機翻
  - [ ] 1 個英文主問題
  - [ ] 5-9 個英文變體（數量必須相同）
  - [ ] 英文答案（摘要 + 詳細）
- [ ] **泰文翻譯** - 完整翻譯，非機翻
  - [ ] 1 個泰文主問題
  - [ ] 5-9 個泰文變體（數量必須相同）
  - [ ] 泰文答案（摘要 + 詳細）
- [ ] **品質檢查**
  - [ ] 沒有遺漏或多餘的句子
  - [ ] 沒有格式錯誤（如拖尾逗號、不匹配的引號）
  - [ ] 專有名詞統一

## 常見問題

### Q1: 能用 Google Translate 翻譯嗎？

**A**: 不建議。Google Translate 對於 FAQ 這種結構化內容：
- ✅ 可以用來做初稿
- ❌ 但不能直接用於生產環境
- 需要人工審核並修正

### Q2: 如果只翻譯英文，泰文先欠著呢？

**A**: 不行。這樣會導致：
- ❌ 泰文用戶看不到正確的 FAQ
- ❌ SEO 泰文搜尋無法優化
- ❌ 拖累整個發布進度
- 建議要麼一起完成，要麼先發中英版本

### Q3: 翻譯品質不好能改嗎？

**A**: 可以。我會在檢查時標記出：
- 文法錯誤
- 意思不對
- 格式問題
- 然後你修正

但這會多花 1-2 天時間，計畫要往後推。

### Q4: 如果我根本沒時間翻譯呢？

**A**: 兩個選擇：
1. **聘請翻譯者** - 費用 $200-600 / 20-30 個 FAQ
2. **推遲計畫** - Phase 0B 延後，但 Phase 0A 先開始（不依賴翻譯）
