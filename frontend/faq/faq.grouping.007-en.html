Family class arrangement

Can I take classes with friends or family? Can different levels attend the same class?

ID: faq.grouping.007

Answer

It is possible to arrange for students to be in the same class, but when there is a significant difference in their proficiency levels, it is recommended to separate them into different classes to ensure that each student receives an appropriate learning pace.

Postscript

For more information and the latest availability, please refer to the reservation system.
